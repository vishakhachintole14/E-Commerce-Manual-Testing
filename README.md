
# E-Commerce Manual Testing Project

## Project Overview
This project demonstrates practical Manual Testing and API Testing activities performed on an E-Commerce website using Postman, Excel and Jira.

## Tools Used
- Microsoft Excel – Test Case Design and Test Execution
- Postman – API Testing
- Jira – Bug Tracking and Test Management
- GitHub – Project Documentation

## Manual Testing
Created and documented 11 test cases covering:
- User Registration
- User Login
- Product Cart
- Cart Total Calculation
- Checkout
- Empty Cart Validation
- Duplicate Email Validation

## API Testing

Tested the following HTTP methods using Postman Echo API:

| API Method | Endpoint | Expected Status |
|---|---|---|
| GET | /get | 200 OK |
| POST | /post | 200 OK |
| PUT | /put | 200 OK |
| DELETE | /delete | 200 OK |

Verified API response status codes and JSON request/response data.

Note: Postman Echo is a testing service that echoes request data. It does not permanently create, update or delete database records.
